# Roadmap

## v0.1

- Local schema DSL.
- Ingest text/markdown/PDF.
- Heuristic entity and relation extraction.
- JSON store.
- CLI and FastAPI.

## v0.2

- LLM extractor interface.
- JSON-schema constrained extraction.
- Entity normalization and alias resolution.
- Relation validation rules.

## v0.3

- PostgreSQL + pgvector adapter.
- Neo4j or Memgraph adapter.
- Hybrid retrieval: keyword + vector + graph.

## v0.4

- Evidence-first answer generation.
- Human review workflow.
- Conflict detection.
- Temporal validity for relations.

## v1.0

- Multi-domain projects.
- Connector system.
- Evaluation harness.
- Web UI.
